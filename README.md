# 🏫 社会科 論述力向上トレーニング（Chromebook / Googleスプレッドシート連携対応）

中学校社会科学習指導要領（地理・歴史・公民）に完全準拠した、論述力向上トレーニング＆AI添削Webアプリケーションです。

## 🌟 特徴
- **新学習指導要領「社会的な見方・考え方」完全対応**: 「効率と公正」「対立と合意」「希少性」「人間と自然環境」「持続可能性」など、定期試験・高校入試頻出の良問を全114問収録。
- **全問に高品質な模範解答例完備**: ボタンをクリックするまで隠れるアコーディオン方式。
- **Googleスプレッドシート自動連携**: 生徒がChromebookで提出すると、教員のスプレッドシートへリアルタイム自動記録。
- **単元・時代別絞り込み**: 授業進度や定期テスト範囲に合わせてピンポイント演習が可能。

## 🚀 使い方
公開URLを開き、クラス・番号・氏名を入力して問題を選択するだけで、誰でもすぐに学習を開始できます。
